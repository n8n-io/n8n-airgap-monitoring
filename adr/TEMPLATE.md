## Status

Accepted/Superseded/Deprecated

A status defining the state of this ADR.

An ADR begins its life within a Pull Request.
The PR can be marked as a Draft while the author is still writing the ADR.
When it is ready for feedback, the author marks the PR as "Ready for review" and sets the status in this document to:

- Accepted - The decision has been agreed upon and the ADR has been merged. It is considered the current state.
- Superseded - The decision has been replaced by a newer ADR. The PR that supersedes this one should link to the new ADR.
- Deprecated - The decision is no longer relevant and has been archived.
